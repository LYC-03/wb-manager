想要独立 App 窗口（没有地址栏、像本地软件）： 用 Chrome 或 Edge 打开本页 → 地址栏右侧「安装」图标 →「安装为应用」。 以后从开始菜单/桌面启动，就是独立窗口。手机端没有 WorkBuddy 本地数据，不需要管。

WorkBuddy 的数据目录（对话正文、缓存都在里面）默认在 C 盘用户目录， 用久了会越来越大。想把整个数据目录搬到其他盘、且 WorkBuddy 一切照旧，做法是「搬走 + 目录联接」：

  1. 完全退出 WorkBuddy（含右下角托盘）
  2. 把 C:\Users\你的名字\.workbuddy 整个文件夹剪切到其他盘，比如 D:\wb-data
  3. 用管理员身份打开命令行，执行：
    mklink /J "C:\Users\你的名字\.workbuddy" "D:\wb-data"
  4. 重新打开 WorkBuddy，一切照旧，C 盘只占一个链接的位置

联接对 WorkBuddy 完全透明，本工具搬家前后也都能正常找到数据库。 动手前先用「备份一次」留个底。

    3. 把返回的 json 粘到下面「导入结果」里，再刷新，建议标题就换成了 AI 给的。
