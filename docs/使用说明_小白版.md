# 给第一次用的人：wb-manager 怎么用

> 这份是「不想看技术细节，只想赶紧把侧栏收拾干净」的人看的版本。
> 里面没有命令、没有数据库术语。想了解原理，看 [README](README.md)。

---

## 一、它解决什么问题

WorkBuddy 用久了，侧栏会长出一堆这样的会话：

- 「新建会话 2026-08-11 2030」——完全不知道当时在干嘛
- 「再问一下」——问的什么？想不起来
- 一堆会话全挤在默认空间里，找不到属于某个项目的

这个工具就是干这事的：**一次把几十上百条会话改成看得懂的名字，把该归位的挪回项目目录，把不用的收进归档。**

它不装在 WorkBuddy 里面，是从外面读它的数据。所以能做到对话里做不到的事：一次改一批。

**你的数据不会离开这台电脑。** 工具只读写本机文件，没有联网上报。不配置 AI 起名的话，它完全离线。

---

## 二、下载和放置

1. 到仓库的 [Releases](https://github.com/LL887526/wb-manager/releases) 页下载 `wb-manager.exe`
2. **在桌面或 D 盘新建一个文件夹**，把 exe 放进去
3. 双击它

> **不要放进 `C:\Program Files`。** 那里要管理员权限，工具存不了配置和备份，会弹框提醒你换位置。

exe 放在哪，数据就存在哪。所以放好位置再开始用，别用了一半又挪。

---

## 三、第一次打开

双击后一两秒，会弹出一个没有地址栏的窗口——看起来就是个普通桌面软件。

**第一件事：点右上角「备份一次」。**

虽然每次改动前它都会自动备份，但第一次多存一份不吃亏。备份就存在 exe 旁边那个 `backups` 文件夹里。

---

## 四、界面怎么用

打开先是**主页**，四张卡片是四个入口：

| 入口 | 干什么 |
|---|---|
| 会话整理 | 主力功能。看建议标题、勾选、批量改 |
| 数据急救 | 会话被误删了，来这里捞回来 |
| 工作空间 | 清理空文件夹、看盘还剩多少空间 |
| 备份与还原 | 改坏了，退回到之前某一步 |

顶部三个标签可以随时切换：主页 / 会话整理 / 维护 · 备份。

### 改名字

进「会话整理」，会列出一屏会话，每条有两列：

- **当前标题**：现在叫什么
- **建议标题**：工具根据你说过的话猜的新名字，可以直接点进去改

觉得行就勾上（最左边的小方框），点底部「应用改名」。想全改就点表头那个勾。

改完回到 WorkBuddy，**点一下别的会话再点回来**，标题就刷新了——它不监听外部改动，得手动触发一下。

### 把会话挪回项目目录

1. 勾选要挪的会话
2. 点底部「移到空间」
3. 每一行都有一个下拉框，分别选目标目录（可以每条去不同地方）
4. 点「检查」——这一步只看不动，会告诉你哪条能挪、哪条不能、为什么
5. 看清了再点「确认搬运」

会显示「跳过」的几种情况，都是在保护你：

| 看到这个 | 意思 |
|---|---|
| 正在使用中 | 这条会话刚被写过，搬走会让 WorkBuddy 找不到内容。等几分钟再搬 |
| 找不到正文文件 | 磁盘上没这个文件，强行搬会变成空会话 |
| 目标已有同名文件 | 防止覆盖已有的东西 |
| 目录没变 | 它本来就在那儿 |

### 归档不用的会话

勾选 → 点底部「归档」→ 确认 → **重启 WorkBuddy**，它们就从侧栏消失了。

数据一条没删，在 WorkBuddy 的「设置 → 归档的任务」里还能找到，也能随时放回来（筛选栏选「已归档」，勾上，点「取消归档」）。

> 顺带一个冷知识：WorkBuddy 自己的自动清理会**跳过归档的会话**。所以归档不只是让侧栏清爽，还是给老会话上了一份保险。

## 五、改错了怎么退

三个层次，从小到大：

| 想退什么 | 怎么做 |
|---|---|
| 退掉刚才那一步 | 「维护 · 备份」→ 操作历史 → 找到那条 → 点「撤回」 |
| 退到某个时间点 | 「备份与还原」→ 找到那次操作**之前**的存档 → 点「还原到这时」 |
| 全都不用管了 | 直接删掉整个文件夹。它没往系统里装任何东西，你的会话还在，只是标题回到整理前 |

自动快照最多留 50 份，更早的会被挤掉。看到「快照已过期」的记录就撤不回来了，所以大动作之前可以手动点一次「备份一次」。

## 六、数据在哪，怎么搬家

所有东西都在 exe 旁边：

```
你的文件夹\
  wb-manager.exe
  backups\        ← 自动快照
  history\        ← 操作历史
  config.json     ← 只有你填了 AI 的 Key 才有
```

**换电脑**：整个文件夹拷过去就行，配置和备份一起带走。

**卸载**：删掉文件夹。就这么简单，没有注册表、没有服务、没有残留。

## 七、AI 起名（可选）

如果你的标题总是「新建会话」这种，规则引擎猜不出你在干什么。接个 AI 就准得多。

工具支持 DeepSeek 等兼容 OpenAI 接口的服务。在「AI 命名 → API 设置」里填地址、模型名、Key 就行，Key 只存本机。

一次整理的花费：30 条约 6 千到 8 千 token，按现在的价格是几分钱。

**不想花钱也有办法**：点「导出命名请求」，它会生成一个文件；把文件路径发给任何一个 AI 对话，让它按文件里的要求回一份 JSON；再把结果粘回来导入。全程不联网也可以。

## 八、常见问题

| 遇到这个 | 怎么办 |
|---|---|
| 双击没反应 | 多半是放在需要管理员权限的目录。挪到桌面或 D 盘再试；如果弹了框，按框里说的做 |
| 弹框说「文件夹不能写入」 | 同上，换个位置放 |
| 改完 WorkBuddy 里没变 | 它不监听外部改动。切换一下会话，或重启 WorkBuddy |
| 提示「数据库正被占用」 | WorkBuddy 正在写。等几秒重试，或先退出 WorkBuddy 再操作 |
| 一堆「需确认」 | 规则没认出这些会话。手动改，或者用 AI 起名 |
| 定时任务的会话太多 | 主页有「归档 30 天前的定时对话」，一键清静 |
| 杀了毒软件报警 | PyInstaller 打包的程序常见误报，源码就在仓库里，可以自己看 |

## 九、它不做的事

说清楚边界，免得你担心：

- 不删你的会话
- 不改对话内容
- 不动模型设置和用量记录
- 不上传任何数据
- 只支持 Windows（macOS / Linux 上会主动停用搬家功能，因为目录规则没验证过，算错会让会话打不开）

这是非官方工具，直接读写 WorkBuddy 的本地数据库。官方升级改了表结构的话，工具可能报错——到时候改工具就行，你的数据本身是安全的。
